Results you can verify

Before each release, the numbers the app prints are compared with values computed independently in Python and in R, and every NIST reference dataset is run. You can repeat the checks on your own computer from Help › Verify this installation.

Work you can repeat

Everything you do in the menus is recorded as a command you can edit and run again. Save the script for next month's data, or export a bundle that a colleague can re-run and check against the original.

How reproducibility works

  • Your metadata comes with you

    SPSS, Stata and SAS files keep their variable labels, value labels and missing-value codes.

  • Charts for publication

    Change titles, colours and legends in place, and export to SVG, PDF or PNG.

  • An optional AI assistant

    Ask in plain language and get the same tables the menus produce. Use Claude, an OpenAI-compatible service or a local Ollama model.

  • Python and the command line

    Drive the same engine from Python with pip install chakatastat, or run a script without opening a window.

  • A spreadsheet data editor

    Edit data directly, with a Variable View for labels, measurement levels and missing values.

  • Fast on large files

    A native engine does the work in the background, so the window stays responsive during long fits.

Tested against independent references

These checks run on every release. The results, tolerances and sources are published in full.

    statistics compared with results computed in Python and in R, across 53 procedure families.

    NIST reference datasets, every one NIST publishes, scored by digits of agreement with the certified values.

  • 3,264

    automated tests of the engine and the app, run before each release.

When a statistic has more than one accepted definition, such as a quantile method or a continuity correction, the choice is written down. Each page of the User Guide says how its results are computed.

Scripting

Use the menus, a script, or Python

The menus, the script editor, the Python client and the command line all run the same commands on the same engine. A result you got by clicking can be run again from a script. 

// Written for you as you use the menus. Edit and run it again.
descriptives variables=[Age, BMI, SystolicBP]
independent_ttest variables=[SystolicBP], grouping=Hypertensive
# The calculations run in the ChakataStat engine, not in Python.
import chakatastat as ig

with ig.open("health_study.ckd") as ds:
    print(ds.descriptives(variables=["Age", "BMI", "SystolicBP"]))
    ds.independent_ttest(variables=["SystolicBP"], grouping="Hypertensive")

    df = ds.to_polars()          # continue in Polars
# Run a script without opening a window and write a report.
ChakataStat --run analysis.cks health_study.csv --out report.html

# Offer the same tools to another program over MCP.
ChakataStat --mcp health_study.csv
// Ask in plain language. The reply shows the real tables and charts.
Compare systolic blood pressure between the hypertensive
and non-hypertensive groups, and show me the effect size.

The Analyze menu

115 tools, grouped the way you work

Full list of commands

Describe and tabulate

Frequencies, descriptives, explore, crosstabs, custom tables, missing values and multiple imputation.

Compare groups

t tests, equivalence tests, one-way ANOVA with post hoc tests, GLM, repeated measures and MANOVA.

Regression

Linear, logistic, Poisson, negative binomial, ordinal, multinomial, quantile, robust, regularized, nonlinear and instrumental variables.

Mixed and panel models

Linear mixed models, GLMM, GEE, panel fixed and random effects, and mediation with moderation.

Survival

Kaplan–Meier, Cox regression, parametric survival and competing risks.

Time series

ARIMA, exponential smoothing, seasonal decomposition, stationarity tests, VAR and Granger causality.

Multivariate

Factor analysis, confirmatory factor analysis, reliability, clustering, discriminant analysis, latent class and item response theory.

Clinical and study design

ROC curves, Bland–Altman, meta-analysis, propensity scores, survey designs, power analysis and bootstrap intervals.

Nonparametric and Bayesian tests sit beside their classical counterparts.
