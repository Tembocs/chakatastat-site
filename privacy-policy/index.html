Privacy Policy

Last updated: August 23, 2026 — the contact address only. ChakataStat's data practices, described below, have not changed since July 15, 2026.

ChakataStat is a desktop application for statistical analysis. This page explains what data the app and this website collect — which, by default, is nothing — and the one case where data leaves your device: if you choose to use the optional AI assistant.

The short version

  • No account, sign-up or registration is required to use ChakataStat.
  • No telemetry, analytics or usage tracking is built into the app today.
  • Your datasets stay on your device. ChakataStat never uploads them anywhere on its own.
  • The AI assistant is optional. It only sends data if you turn it on, configure a provider, and use it.
  • This website does not use cookies, analytics scripts, or any third-party tracking.

Your data and datasets

ChakataStat runs entirely on your computer. The files you open, edit and analyze are read from and written back to your own disk. Nothing about your data — its contents, file names, variable names, or the analyses you run — is sent to ChakataStat or anyone else, unless you explicitly use the AI assistant described below.

The AI assistant

ChakataStat includes an optional, provider-neutral AI assistant. It does nothing until you configure it with your own API key for a provider — Anthropic, an OpenAI-compatible service, or a local Ollama instance running entirely on your machine.

When you use the assistant, your prompt — which may include data you choose to reference from your open dataset — is sent directly to the provider you configured, under that provider's own privacy terms. If you configure a local Ollama backend, nothing leaves your device at all. ChakataStat's own servers are not part of this path today: there is currently no ChakataStat-hosted AI service, so no data is ever sent to us through the assistant.

Telemetry and analytics

ChakataStat does not currently collect installation counts, usage statistics, crash reports, or any other telemetry. If anonymous, opt-in usage telemetry is added in the future, it will be disclosed here first, require your explicit consent before anything is sent, and will never include dataset contents, file names, or analysis details.

This website

chakatastat.app is a static site with no cookies, no analytics, and no third-party trackers. It's hosted on GitHub Pages, which may log standard, aggregated web-server access data (such as IP addresses) as part of its own infrastructure — ChakataStat has no access to that data.

Changes to this policy

If ChakataStat's data practices change — for example, if an optional hosted AI service is introduced — this page will be updated before that change takes effect, and any new data collection will be opt-in and clearly disclosed.

Contact

Questions about this policy can be sent to contact@chakatastat.app.
