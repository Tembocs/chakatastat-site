Cross-OS agreement

Part of the numerical-validation suite. What the three operating systems' engines compute relative to each other, per pinned statistic — the statement the tolerances cannot make.

The validation suites hold every pin within its tolerance of the reference on each OS, and stop there: a pin that passes on one OS at one value and on another at a slightly different value is invisible, because the tolerance swallows the difference. This report makes the difference visible. With VALIDATION_EMIT_PINS set, every suite also writes the value the engine actually computed; the tier-2 matrix uploads one file set per OS and a job after it puts them side by side. Per pin, the score is the number of significant digits on which every OS agrees — −log₁₀(spread / max |value|), capped at 16, the double limit — so 16 means bit-identical. A spread wider than the pin's own tolerance is a finding: a real platform difference to fix, or a convention to record.
