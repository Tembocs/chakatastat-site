How to cite ChakataStat

Last updated: September 25, 2026

ChakataStat is archived on Zenodo, which gives it two kinds of DOI. Use the first to refer to the software in general, and the second to refer to the exact release that produced your results.

Citing the software

Use the concept DOI when you mean ChakataStat in general, for example in a methods section that names the tool or in a link that should keep working after the next release. It never changes. It always leads to the newest version, with every earlier version listed below it.

Amani, E. (2026). ChakataStat [Computer software]. https://doi.org/10.5281/zenodo.22112256

Citing the version you ran

Use a version DOI when the result has to be reproducible, for example in a paper that reports statistics computed with ChakataStat, a pre-registration or a submitted analysis script. It points to one release, so a reader can find the exact version you used and its archived files. ChakataStat shows its version under Help → About and at the bottom of every output document.

Amani, E. (2026). ChakataStat (Version 0.24.0) [Computer software]. https://doi.org/10.5281/zenodo.22764163

Releases before 0.20.0 were made before the archive existed and have no DOI. Cite them with the concept DOI and the version number.

From 0.22.0 on, Zenodo creates each version record from the release on GitHub and archives that release's public repository. The Linux installer and its SHA256SUMS.txt checksums are attached to that release. The 0.20.0 and 0.21.0 records were archived by hand, with the installer included, under an earlier concept DOI, 10.5281/zenodo.22043444, which still works.

A version DOI identifies the release, not the installer. Whether you ran the Windows or the Snap build of 0.24.0, you cite the same DOI.

BibTeX

@software{chakatastat,
  author  = {Amani, Edward},
  title   = {ChakataStat},
  year    = {2026},
  version = {0.24.0},
  doi     = {10.5281/zenodo.22764163},
  url     = {https://doi.org/10.5281/zenodo.22764163}
}

To cite the software rather than one release, remove the version field and use 10.5281/zenodo.22112256 as the DOI.

If a reviewer asks how the results were checked

Point them to the validation report. It lists every statistic that is compared with an independently computed reference value, the tolerance used for each, the NIST reference datasets with their digits of agreement, and the definition chosen wherever a statistic has more than one accepted form.
